Zmienne środowiskowe:  

PORT: Port, na którym nasłuchuje serwis (domyślnie 3004)  
JWT_SECRET: Sekret używany do weryfikacji tokenów JWT (podczas testów lokalnych powinien być zgodny z auth-service)  
DB_STORAGE: Ścieżka pliku SQLite (np. ./order.sqlite)  
PROFILE_SERVICE_URL: Adres serwisu profili (np. http://localhost:3002)  
PRODUCT_CATALOG_SERVICE_URL: Adres katalogu produktów (np. http://localhost:3003)
