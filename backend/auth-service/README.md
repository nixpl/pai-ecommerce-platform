Zmienne środowiskowe:

PORT: Port, na którym nasłuchuje serwis (domyślnie 3001)
JWT_SECRET: Sekret używany do podpisywania tokenów JWT (wymagane)
DB_STORAGE: Ścieżka pliku SQLite (np. ./auth.sqlite)
SUPER_ADMIN_EMAIL: Email konta super admina, tworzonego przy starcie (seed)
SUPER_ADMIN_PASSWORD: Hasło konta super admina, tworzonego przy starcie (seed)
